# Network Packet Analysis

## Objective
Capture and analyze network traffic.

## Tool Used
Wireshark

## Steps Performed

1. Started packet capture
2. Generated network traffic by opening a website
3. Applied filters

dns  
http  
tcp

## Findings

DNS query observed resolving domain name to IP address.

HTTP packets captured showing request and response between client and server.

## Learning Outcome

Learned how network communication occurs and how analysts inspect traffic for suspicious activity.
