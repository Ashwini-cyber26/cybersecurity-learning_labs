# Web Application Security Testing Lab

## Objective
Understand common web vulnerabilities.

## Tools Used

Burp Suite
OWASP Juice Shop
DVWA

## Steps Performed

1 Installed vulnerable web applications using Docker.

2 Configured Burp Suite proxy.

3 Intercepted HTTP requests.

4 Observed vulnerabilities related to OWASP Top 10.

## Learning Outcome

Gained understanding of how web application vulnerabilities can be discovered and analyzed.
